## Project Management Skill

When working with projects and repositories:

- Use list_directory to explore the project structure
- Use search_files to find configuration files (.json, .yaml, .toml, etc.)
- Use grep_files to find project metadata, version info, or dependencies
- Check for common project files: README.md, LICENSE, requirements.txt, package.json, etc.
- Use file_info to check when files were last modified
- Use watch_file to compare file versions or track changes
- Examine git history to understand recent changes
- Look for CI/CD configuration files
- Check for documentation directories
- Identify the build system and packaging

Project analysis workflow:
1. Start with the root directory structure
2. Find and read README for overview
3. Identify configuration and dependency files
4. Understand the build system
5. Locate tests and documentation
6. Check for CI/CD setup
7. Examine recent git history for context
8. Identify active development areas
